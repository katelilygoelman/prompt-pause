# Prompt Pause

A browser extension that adds a moment of pause before you send a prompt to an AI chat.

- Pressing Enter won't send your message.
- The Send button unlocks a few seconds after you stop typing (3 seconds by default), and needs a real mouse click.
- You can turn it on for extra sites from the extension's pop-up.

Prompt Pause collects no data. Everything stays in your browser.

- Chrome Web Store: https://chromewebstore.google.com/detail/prompt-pause/kiihjfgokodfjgomdjaialcjjchbaahh
- Website: https://promptpauseai.netlify.app
- Privacy: https://promptpauseai.netlify.app/#privacy
